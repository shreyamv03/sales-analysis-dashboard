# sales-analysis-dashboard
Sales Data Analysis using Python, Excel, and Power BI

Project Overview:
This project analyzes retail sales data to identify key trends in revenue, profitability, and product performance. The goal is to support data-driven decision-making through interactive dashboards and clear insights.

Key Features:
Data cleaning and transformation using Python (pandas),
KPI analysis and financial summaries in Excel,
Interactive Power BI dashboard with filters and visualizations,

Key Insights:
Technology category generates the highest sales,
Sales show a consistent upward trend over time,
Office Supplies has high volume but lower profit margins,
